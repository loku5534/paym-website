# Paym Technology website

Static site. No build step. Upload the files to any host (Cloudflare Pages, Netlify, GitHub Pages, cPanel).

## Replace before launch
1. Domain: find and replace `https://www.paymtechnology.com` in all .html files, sitemap.xml and robots.txt.
2. Email and phone: `hello@paymtechnology.com` and `(800) 555-0142` / `+18005550142` (the phone is a fictional placeholder).
3. Contact form: create a free form at formspree.io and replace `YOUR_FORM_ID` in contact.html.
4. Business claims: confirm the free consultation, reply time, hours, account ownership policy and company size range match how you actually operate.
5. Add a real street address to the footer, contact page and the Organization schema if you have one (needed for Google Business Profile and local SEO).
6. Add a privacy policy page before collecting form data.

## After launch
- Submit sitemap.xml in Google Search Console and Bing Webmaster Tools.
- Test structured data at https://search.google.com/test/rich-results
